# Android and SSH controls

VStab commands for SSH hosts, Android files and workspace windows.

Edit `src/extension.cjs`, `src/native-client.js` and `extension/documents-ui.js`.

```sh
node workbench/controls/build.mjs
node --test workbench/controls/*.test.*
```
