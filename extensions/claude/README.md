# Claude Code

In an SSH workspace, install **`Anthropic.claude-code`** from Extensions.
The inspected package requires a Linux x64 host. Sign in through the extension.

Inspect the pinned package:

```sh
python3 scripts/claude-package.py --download --inspect
```
