# Codex and Claude Code

Install these extensions in a Linux x64 SSH workspace:

| Extension | ID |
| --- | --- |
| OpenAI Codex | `openai.chatgpt` |
| Claude Code | `Anthropic.claude-code` |

1. Connect to an SSH host.
2. Open **Extensions**, search the ID and install the publisher's extension.
3. Open its sidebar and sign in with your provider account.

Install separately on your Linux SSH host; local Android execution is not supported.

Signed-in AI workflows: unverified.
