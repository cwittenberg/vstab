# Workspaces

## Windows

- Run **vstab: New Workspace Window...** for another Android or SSH project.
- Up to four windows; arrange them with Android split screen or desktop windowing.
- Closing one window leaves the others open.

## Named persistent terminals

- Run **vstab: New Persistent Terminal...** and enter a name.
- Reattach from Explorer → **Persistent Terminals** after reload or SSH reconnect.
- Closing a terminal tab detaches it. **Stop Persistent Terminal...** ends it.
- Android force-stop, reboot or process killing ends local sessions.

## Android files and shared projects

- **vstab: Open Shared Folder...** opens an Android folder and retains Git history.
- **vstab: Open Android File...** or Android **Open with → VStab** opens one file.
- Saves write back; external edits synchronize while the project is open.
- Concurrent changes retain both versions. Use **Review Shared-file Conflicts...** to compare them.
- **Sync Shared Files Now** requests an immediate sync.
- Shared folders: up to 20,000 entries, 256 MiB per file and 1 GiB per scan.

## Extension compatibility

Failed extensions show a warning with **Show details**. Use **vstab: Show Extension Compatibility Report** for details.
